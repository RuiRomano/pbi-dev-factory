# Attributions

This project uses the following community tools and contributions:

- [Tabular Editor](https://tabulareditor.com/) for running Best Practice Analyzer (BPA) rules against semantic models.
- [FAB Inspector](https://github.com/NatVanG/fab-inspector) by [Nat Van Gulck](https://www.linkedin.com/in/natvangulck/) for running Best Practice Analyzer (BPA) rules against Power BI reports.
- [PQL.Assert](https://daxlib.org/package/PQL.Assert) by [John Kerski](https://www.linkedin.com/in/john-kerski/) for assertion-based semantic model data tests.
- [PBIR A11y](https://github.com/Juls-BI/pbir-a11y) by [Juliana Smith](https://www.linkedin.com/in/juliana-smith-citp/) for Power BI report accessibility checks.

## Community inspiration

Thanks to [Kurt Buhler](https://www.linkedin.com/in/kurtbuhler/) and [Maxim Anatsko](https://www.linkedin.com/in/maxanatsko/) for pushing the boundaries of agentic Power BI development. [Power BI Agentic Development](https://github.com/data-goblin/power-bi-agentic-development) skills and [PBIR-CLI (pbir.tools)](https://github.com/maxanatsko/pbir.tools) give agents practical tools for working with Power BI.
