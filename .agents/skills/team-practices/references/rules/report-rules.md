# Report Development Rules

- Use the [Contoso theme](./contoso-theme.json).
- Follow the [Contoso design standards](./contoso-design-standards.png) for colors, typography, layout, and logo usage. The image is a brand reference, not a report page template.
- For existing reports, apply these rules only when design changes are in scope. Do not restyle unrelated pages or visuals.
- Don't use more than one slicer per page, use the filter pane
- Don't exceed more than 20 visuals per page, unless justified
