# Power BI project instructions

## Skill routing

Load the required skill before starting the task:

- Semantic model changes: load `semantic-model-authoring`.
- Report changes: load `powerbi-report-cli`.
- Project documentation: load `powerbi-documentation`.

If a task covers more than one area, load every applicable skill.

## Tools

- Use `powerbi-authoring-remote` when authoring against semantic models in Fabric workspaces
- Use `powerbi-authoring-local` when authoring against semantic models in Power BI Desktop or PBIP tmdl folder
